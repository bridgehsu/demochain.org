# DemoChain 文档

DemoChain 是一个面向学习者的区块链共识机制**可视化演示平台**，通过交互式动画帮助你直观理解区块链的运作原理。

## 包含哪些内容

本文档涵盖七种主流共识机制，每种机制都有对应的概念解读和在线演示：

| 共识机制 | 核心思想 | 代表项目 |
|---------|---------|---------|
| **PoW** 工作量证明 | 算力竞争出块，消耗能量换取安全 | Bitcoin、Litecoin |
| **PoS** 权益证明 | 质押代币参与验证，节能高效 | Ethereum、Cardano |
| **DPoS** 委托权益证明 | 持币者投票选出代表出块 | EOS、TRON |
| **PoA** 权威证明 | 受信任的权威节点轮流签名出块 | Polygon PoA、BSC |
| **BFT** 拜占庭容错 | 多轮投票达成即时最终性 | Cosmos、Tendermint |
| **Avalanche** 雪崩协议 | 重复随机采样快速收敛 | Avalanche |
| **PoH** 历史证明 | 连续哈希序列作为可验证时钟 | Solana |

## 如何使用本文档

1. **阅读原理** — 在文档中了解每种共识机制的工作原理
2. **动手演示** — 点击文档内的「去演示」按钮，在交互页面中实际操作
3. **对比理解** — 通过不同共识机制的横向对比加深理解

## 从哪里开始

如果你是区块链新手，建议从 [PoW 工作量证明](/docs/pow/) 开始——它是最直观也是历史最久的共识机制，许多核心概念（哈希、区块、链）在这里都有清晰的演示。
