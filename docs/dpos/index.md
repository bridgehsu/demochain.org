# DPoS 委托权益证明

**委托权益证明（Delegated Proof of Stake）** 是 PoS 的一种变体，由 Dan Larimer 设计，EOS、TRON 等项目采用。

## 核心思想

DPoS 引入了"代表（Delegate）"制度：所有持币者**投票**选出一定数量的代表（通常 21 个），由这些代表轮流出块。

```
普通 PoS：所有质押者都有机会随机出块
DPoS：持币者投票 → 选出 N 位代表 → 代表按固定顺序轮流出块
```

## 类比民主选举

DPoS 的设计思路类似于代议制民主：普通持币者不直接参与治理，而是委托投票给信任的代表，由代表代为行使出块权。

## 优缺点

**优点**
- 出块速度极快（EOS 每 0.5 秒一块）
- 代表数量少，网络通信高效
- 社区可以投票罢免表现不佳的代表

**缺点**
- 高度中心化（21 个代表控制整条链）
- 投票参与率低，少数大户可控制选举
- 代表之间可能形成利益勾连
