# 期权交易总览

期权是与现货、合约并列的核心业务域。当前工作空间具有三套期权业务实现及三套行情模块，其中触碰期权 README 明确标注为触碰二元期权业务。

## 本组目录

- [模块与版本边界](/tgex/option/modules/)：区分业务工程、行情工程与聚合目录。
- [期次与购买流程](/tgex/option/orders/)：从新版 add 入口追踪购买校验。
- [交割结算与账户处理](/tgex/option/settlement/)：核对调度、状态、单笔结算与资金变更。
- [触碰期权判定](/tgex/option/touch/)：区间高低价、方向幅度及最终结果分支。
- [期权行情与周期数据](/tgex/option/market/)：配套行情服务与结算数据边界。

## 与撮合业务的区别

已读取的新版实现通过期次、购买和到期结算组织订单，不应描述为“委托进入现货订单簿并按价格撮合”。同样不能把这一套实现泛化为所有期权产品或生产版本。
