# 惩罚（Slashing）

Slashing 是 PoS 安全机制的核心——通过没收作恶验证者的质押代币来威慑恶意行为。

## 什么行为会被惩罚

**双重签名（Double Signing）**：验证者对同一高度的两个不同区块都进行了签名，试图在两条链上都占位。这是最严重的违规行为。

**长程攻击签名**：验证者签名了一个与当前链历史冲突的旧区块。

## 惩罚机制

一旦被检测到违规，智能合约会：

1. 没收部分或全部质押代币（比例根据参与作恶的验证者数量而定）
2. 将该验证者从活跃集合中移除（不能再出块）
3. 经过一段强制退出等待期后才能提款

## 相关性惩罚

以太坊有一个特别的设计：如果许多验证者**同时**被 Slash，每个人被没收的比例会更高。这鼓励验证者使用多样化的客户端和基础设施，防止单一故障导致大规模惩罚。

```
1 个验证者被 Slash：损失少量质押
1000 个验证者同时被 Slash：每人损失大量质押，可能超过 50%
```

## 经济安全分析

Slashing 的设计让作恶的预期损失远大于预期收益：

```
预期收益 = 成功攻击的获利 × 成功概率（极低）
预期损失 = 质押金额 × 没收比例（较高）
```

理性的验证者不会选择作恶。
