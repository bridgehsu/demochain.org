# 权威节点

权威节点（Authority Node / Validator）是 PoA 系统的核心，它们负责验证交易、打包区块。

## 成为权威节点的条件

与 PoS/PoW 不同，PoA 的节点准入是**许可制**的：

- 需要通过身份验证（KYC）
- 通常由治理委员会投票决定
- 需要保证节点稳定运行（高可用性）
- 同意遵守网络规则和行为准则

## 节点状态

权威节点有以下几种状态：

| 状态 | 说明 |
|------|------|
| **活跃** | 正常参与出块 |
| **已暂停** | 临时停止出块（如维护） |
| **已移除** | 被投票踢出权威集合 |

## 节点管理

在 PoA 中，已有的权威节点可以投票**添加或移除**其他节点。通常要求超过 50% 的现有节点同意才能执行。这种机制防止了单个节点的独裁。

## 在演示中体验

在权威演示页面，你可以：
- 查看所有权威节点的当前状态
- 模拟添加新的权威节点（Node4）
- 观察节点状态的变化对链的影响
