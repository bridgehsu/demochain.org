# PoS 权益证明

**权益证明（Proof of Stake）** 是目前最主流的新型共识机制，以太坊于 2022 年完成"合并"后正式从 PoW 切换至 PoS。

## 核心思想

PoS 用**质押（Staking）代币**替代了 PoW 的算力竞争。验证者将自己的代币锁定作为保证金，获得参与验证和出块的资格。

```
PoW：算力越强 → 出块概率越高
PoS：质押越多 → 出块概率越高
```

## 验证者如何选出

系统根据验证者的质押权重进行**加权随机抽签**，质押越多的验证者被选中的概率越高，但不是绝对的——质押少的验证者也有机会被选中，只是概率较低。

## Slashing 惩罚

PoS 的安全性依赖于**经济惩罚（Slashing）**：如果验证者作恶（如对同一高度签名两个不同区块），其质押的代币会被部分或全部没收，并被踢出验证者集合。

惩罚让作恶的经济代价远大于收益，从而保障网络安全。

## 优缺点

**优点**
- 能耗极低（以太坊合并后能耗降低约 99.95%）
- 出块速度快，吞吐量高
- Slashing 机制提供直接的经济惩罚

**缺点**
- 富者越富：质押越多，获得的奖励越多，进一步扩大差距
- 对早期持币者更有利，去中心化程度存疑
- 需要长时间锁定资金（流动性风险）
