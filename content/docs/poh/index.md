# PoH 历史证明

**历史证明（Proof of History）** 是 Solana 的核心创新，由 Anatoly Yakovenko 于 2017 年提出。它不是独立的共识机制，而是一种**可验证的时间记录工具**。

## 核心思想

PoH 通过**连续不断的 SHA256 哈希计算**创建一条可验证的时间序列：

```
H0 = SHA256(初始值)
H1 = SHA256(H0)
H2 = SHA256(H1)
H3 = SHA256(H2)
...
Hn = SHA256(H(n-1))
```

由于 SHA256 的单向性，计算 H1000 必须先计算 H999，必须先计算 H998……这个序列**只能按顺序生成**，无法并行加速。

## 作为可验证时钟

这意味着：如果有人能证明他们知道 H1000，就证明他们**确实花时间**执行了 1000 次 SHA256 计算。这个计算量本身就是时间的证明。

Solana 将这条哈希序列当作全局时钟，每一步（Slot）都对应现实世界中的一小段时间。

## 与其他机制的配合

PoH 通常与 PoS 配合使用：
- **PoH**：提供全局时间顺序，让节点快速就事件顺序达成一致
- **PoS**：决定谁有权出块、对区块进行签名确认

这种组合让 Solana 可以达到极高的 TPS（理论值 65000+）。
