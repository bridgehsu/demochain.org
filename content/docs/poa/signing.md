# 签名出块

PoA 中，每个区块由一位权威节点用其**私钥签名**产生，其他节点验证签名有效后接受该区块。

## 轮流签名机制

为了防止单个节点垄断出块权，PoA 通常采用**轮流签名**：

```
节点列表：[Node1, Node2, Node3, Node4, Node5]
出块顺序：Node1 → Node2 → Node3 → Node4 → Node5 → Node1 → ...
```

每个节点有固定的时间窗口签名出块，超时则跳过，由下一个节点接续。

## 连续签名限制

为防止某个节点连续签名控制太多区块，PoA 通常规定：在连续 N 个区块中，同一节点签名的块不得超过一定比例。

## 签名验证

其他节点收到新区块后，会验证：
1. 签名者是否在权威节点列表中
2. 签名者在本轮是否有出块权
3. 区块数据的完整性

三项验证均通过后接受区块，无需任何算力竞争。

## 在演示中体验

在签名演示页面，你可以：
- 点击"单步出块"，观察下一位权威节点签名产生区块
- 启动"自动出块"，看节点按顺序轮流出块
- 观察链上每个区块的签名者信息
