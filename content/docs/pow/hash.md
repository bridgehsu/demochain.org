# 哈希与难度

哈希函数是区块链技术的基石。理解哈希，才能理解区块链的不可篡改性。

## 什么是哈希函数

哈希函数（Hash Function）将**任意长度的输入**映射为**固定长度的输出**。Bitcoin 使用的 **SHA256** 输出始终是 256 位（64 个十六进制字符）。

```
SHA256("Hello")         = 185f8db3...
SHA256("Hello!")        = 334d0162...  ← 输入只差一个字符，输出完全不同
SHA256("区块链")        = a1b2c3d4...
```

## 哈希的关键特性

**1. 单向性**：给你哈希值，你无法反推出原始数据。只能穷举尝试。

**2. 雪崩效应**：输入哪怕改变一个比特，输出会有约 50% 的位发生变化，完全不同。

**3. 确定性**：相同的输入，永远得到相同的输出。

**4. 抗碰撞性**：极难找到两个不同的输入产生相同的输出。

## 挖矿难度

挖矿难度规定了有效哈希必须满足的条件：**结果的开头必须有 N 个零**。

```
难度 = 3 时，有效哈希示例：
000a5f2b8e3c1d7f4a9b0e6c2f1d8a5e3b0c7f9e...

难度 = 5 时，有效哈希示例：
0000098b2e4a1c6f3d9b7e0a5c8f2b4d6e1a3c...
```

难度每增加 1，平均尝试次数大约变为原来的 **16 倍**（因为十六进制每位有 16 种可能）。

## Nonce 的作用

矿工不能修改区块的交易数据，但可以修改一个叫做 **Nonce（随机数）** 的字段。通过不断改变 Nonce 值来计算不同的哈希，直到找到满足难度要求的结果。

```
区块数据（固定） + Nonce（可变） → SHA256 → 哈希值
                                              ↓
                                     是否满足难度要求？
                                     否 → Nonce + 1 → 重试
                                     是 → 广播区块，获得奖励
```
