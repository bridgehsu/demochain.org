# Avalanche 雪崩协议

**Avalanche** 是由 Emin Gün Sirer 等人提出的新型共识协议族，核心思想是通过**重复随机采样**让节点逐渐收敛到同一个结论。

## 核心思想

不同于 BFT 的"全网广播投票"，Avalanche 每轮只询问一小部分随机节点（采样），根据采样结果更新自己的偏好，多轮后所有节点收敛到同一选择。

```
我现在倾向选 A，随机询问 20 个节点：
  15 个说 A，5 个说 B → 继续倾向 A，信心 +1
  8 个说 A，12 个说 B → 转向 B，信心归零
重复多轮，直到信心达到阈值 → 最终确定
```

## 雪球算法

雪球（Snowball）是 Avalanche 的核心子协议：

- 每轮随机采样 k 个节点，询问它们的偏好
- 如果超过 α 个节点（阈值）与自己偏好相同，连续计数 +1
- 连续计数达到 β（置信阈值）后，节点**最终确定**该选择

这就像雪球越滚越大——一旦某个选择获得优势，就会越来越强，直到全网收敛。

## 优缺点

**优点**
- 极高吞吐量（Avalanche 宣称 4500+ TPS）
- 低延迟最终性（1-2 秒）
- 良好的去中心化特性（可支持大量验证者）

**缺点**
- 理论分析复杂
- 在对抗性网络条件下的安全性仍在研究中
- 需要精心调整参数（k、α、β）
