# PoA 权威证明

**权威证明（Proof of Authority）** 是一种许可制共识机制，由少数经过身份认证的权威节点负责出块。

## 核心思想

PoA 放弃了去中心化，以换取极高的性能和确定性。参与出块的节点不需要质押代币或消耗算力，**只需要拥有受信任的身份**。

```
PoW：算力竞争 → 去中心化，但慢且耗能
PoS：权益质押 → 半去中心化，高效
PoA：身份权威 → 中心化，极速且能耗极低
```

## 适用场景

PoA 通常用于：
- **企业/联盟链**：参与方身份已知，互相信任
- **测试网络**：如 Ethereum Sepolia 测试网
- **高性能侧链**：如早期 Polygon（现已升级）

## 权威节点

权威节点通常由可信机构运营（政府、知名企业、基金会），节点运营者需要公开真实身份，以**声誉**作为约束。一旦作恶，不仅质押资产受损，现实身份也会暴露。

## 优缺点

**优点**
- 极快的出块速度（毫秒级确认）
- 能耗极低
- 交易吞吐量高

**缺点**
- 高度中心化，需要信任权威节点
- 权威节点被攻击或勾结则链不再安全
- 不适合无需许可的公链场景
