# PoS 链视图

PoS 链的外观与 PoW 链相似，但每个区块不再有 Nonce 和挖矿难度——区块是由被抽签选中的验证者**直接签名产生**的。

## 区块结构对比

| 字段 | PoW 区块 | PoS 区块 |
|------|---------|---------|
| 高度 | ✓ | ✓ |
| 数据/交易 | ✓ | ✓ |
| Nonce | ✓（挖矿必需） | ✗ |
| 前驱哈希 | ✓ | ✓ |
| 验证者签名 | ✗ | ✓ |
| 出块时间 | 不固定（难度调整） | 相对固定（槽位机制） |

## 最终性

PoW 链没有**绝对最终性**——理论上任何区块都可能被更长链覆盖（但实际上 6 次确认后已极难攻击）。

PoS 系统通常引入**检查点**机制：当超过 2/3 的验证者对某个区块投票确认后，该区块获得**最终性**，之后永远不会被撤销。

## 分叉选择规则

PoS 使用专门的分叉选择规则，如以太坊的 **LMD-GHOST**：选择拥有最多验证者投票支持的链，而非简单的最长链。

## 在演示中体验

在 PoS 链演示页面，你可以：
- 点击"产生新区块"，观察随机选出的验证者
- 多次产生区块，对比每位验证者的出块次数与其质押权重
- 查看链上每个区块的完整信息（验证者、哈希、时间戳）
