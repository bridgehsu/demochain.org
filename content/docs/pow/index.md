# PoW 工作量证明

**工作量证明（Proof of Work）** 是区块链最早、也是最广为人知的共识机制，由中本聪在 2008 年的比特币白皮书中提出。

## 核心思想

PoW 的核心逻辑很简单：**谁先解出一道数学难题，谁就有权打包下一个区块**。这道难题没有捷径，只能靠大量计算反复尝试——这就是"工作量"的由来。

难题的形式是：找到一个叫做 **Nonce（随机数）** 的整数，使得 `SHA256(区块数据 + Nonce)` 的结果满足特定条件（比如开头有若干个零）。

```
目标：SHA256(数据 + Nonce) = 00000abc...
矿工：尝试 Nonce = 1, 2, 3... 直到找到满足条件的值
```

## 难度调整

"开头几个零"就是**挖矿难度**。零越多，满足条件的哈希越难找，平均需要尝试的次数呈指数级增加。比特币每 2016 个区块（约两周）自动调整一次难度，保证平均每 10 分钟出一个块。

## 安全性来源

PoW 的安全性建立在"51% 攻击"的高成本上：要篡改链上数据，攻击者需要掌握超过全网 51% 的算力，并且重新计算从篡改点到链尾的所有区块哈希。随着链越来越长，这个代价越来越高。

## 优缺点

**优点**
- 去中心化程度高，任何人都可以参与挖矿
- 安全性经过十余年实战验证

**缺点**
- 能耗极高，大量算力浪费在无效哈希计算上
- 出块慢（比特币约 10 分钟/块），吞吐量低
- 存在矿池集中化风险
