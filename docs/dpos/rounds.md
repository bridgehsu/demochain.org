# 轮次出块

DPoS 与 PoS 最大的区别之一在于出块顺序：代表按**预先确定的固定顺序**轮流出块，而非随机选择。

## 出块顺序

当选代表的出块顺序在每轮（Round）开始时随机打乱，然后在这一轮内严格按顺序执行：

```
第 1 轮顺序：Alice → Bob → Charlie → Alice → Bob → Charlie → ...
第 2 轮顺序：Charlie → Alice → Bob → ...（重新随机排列）
```

## 时间槽（Slot）

每位代表有固定的出块时间窗口（如 0.5 秒）。在自己的时间槽内必须出块，超时则视为缺块，顺序移到下一位代表。

## 缺块处理

如果某位代表在其时间槽内没有出块（节点离线或故障），链会：
1. 跳过该代表的时间槽，等待下一位代表
2. 记录该代表的缺块率
3. 缺块率过高的代表可能被持币者投票踢出

## 与 PoS 的对比

| 维度 | PoS | DPoS |
|------|-----|------|
| 出块者选择 | 随机抽签 | 固定轮次 |
| 出块时间 | 相对固定 | 严格固定 |
| 可预测性 | 低 | 高 |
| 中心化程度 | 中 | 高 |
