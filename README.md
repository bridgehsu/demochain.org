# Mining Adventure-Style PoW Experience

## 🎯 目标
将传统 PoW 共识相关知识，以“矿山探险”主题重新包装，让用户在学习时能获得更强的沉浸感和参与度，从而提升页面停留时间和回访率。

## 🎨 视觉与品牌风格
- **主色调**：铁青 (`#1a1d24`)、矿石灰 (`#2d2d30`)
- **强调色**：熔岩橙 (`#f97316`)、黄金 (`#fbbf24`)
- **质感元素**：金属拉丝、矿石颗粒、蒸汽雾化等，可通过 CSS 的透明度与滤镜实现。

## 🧩 功能板块对照表
| 菜单项 (游戏名) | 对应 PoW 功能 | 游戏场景设定 | 粘性策略 |
| --- | --- | --- | --- |
| 算力探险 | 哈希演示 | 探矿雷达站：输入字符串或随机挖掘，哈希前导零越多，奖励越高。 | 实时反馈 + 挑战成就 |
| 矿石工坊 | 区块浏览 | 加工流水线：新块产生时触发“锻造完成”动画，展示交易详情。 | 动态动画 + 数据探索 |
| 永恒长廊 | 区块链结构 | 深井矿道：3D 或时间轴展示，滚动即代表深入历史层。 | 时间回溯 + 里程碑事件 |
| 矿工集落 | 节点网络 | 全球营地地图：节点以火盆亮起，可查看各地区算力占比。 | 互动式地图 |
| 金币熔炉 | 代币信息 | 财富铸造厂：代币总量、发行曲线以熔岩/熔炉动画呈现。 | 数据可视化 + 情绪激励 |
| 赏金大厅 | Coinbase 奖励 | 任务榜：展示最新挖矿奖励和“今日矿工英雄榜”。 | 排行榜 + 成就系统 |

## 🏆 成就与成长体系
- **身份等级**：见习矿工 → 资深工头 → 矿业大亨
- **成就示例**：
  - “寻宝者”：发现带有 4 个前导零的哈希值
  - “守望者”：见证 5 个新块生成
  - “商路开拓者”：在矿工集落中为节点命名并分享

## 🧠 推荐交互实现策略
1. **图标动态化**：在 `Menu.tsx` 中通过 `hover:scale-105`、`transition-transform` 等 Tailwind 类实现动效。
2. **动画框架**：引入 `framer-motion` 或 CSS `@keyframes` 增强板块切换时的沉浸感。
3. **数据驱动**：将实时区块数据映射到视觉元素（如熔炉火焰高度、雷达扫描频率）。
4. **状态持久化**：使用 `localStorage` 保存用户称号、成就，强化长期粘性。
