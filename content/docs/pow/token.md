# 代币与转账

区块链不仅是数据的存储结构，还是价值的传输网络。代币（Token）是链上价值的载体，转账（Transaction）是改变代币所有权的操作。

## 交易的结构

一笔基本交易包含：

| 字段 | 说明 |
|------|------|
| **发送方（from）** | 付款账户地址 |
| **接收方（to）** | 收款账户地址 |
| **金额（amount）** | 转移的代币数量 |

在演示中，交易被打包进区块。矿工挖出区块后，交易才算"确认"，余额才真正改变。

## 账户余额模型

与比特币的 UTXO 模型不同，许多区块链（如以太坊）使用**账户模型**：每个地址维护一个余额字段，转账时直接加减余额。

```
Alice 余额：100
Bob 余额：  50

Alice → Bob 转账 30：
Alice 余额：70
Bob 余额：  80
```

## 交易的生命周期

```
1. 用户发起交易（签名确认）
2. 交易进入内存池（mempool）等待打包
3. 矿工选取交易打包进区块
4. 矿工挖矿（找到满足难度的 Nonce）
5. 广播区块，网络确认
6. 交易完成，余额更新
```

## 手续费

矿工有权选择打包哪些交易，通常优先打包手续费（Gas）较高的交易。手续费是对矿工/验证者提供记账服务的报酬。

- 观察区块链上的完整交易记录
