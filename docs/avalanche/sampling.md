# 随机采样

Avalanche 协议的核心创新是用**随机采样**替代全网广播——每个节点不需要和所有其他节点通信，只需要询问一小部分随机节点。

## 采样参数

| 参数 | 含义 | 典型值 |
|------|------|-------|
| **k** | 每轮采样的节点数 | 20 |
| **α** | 触发偏好更新的阈值 | 15（75%） |
| **β** | 最终确定所需的连续成功轮数 | 20 |

## 采样流程

```
1. 节点 X 有一个待确认的事务（偏好 A 或 B）
2. 随机选择 k 个节点，发送询问
3. 收集 k 个节点的回复（他们各自的偏好）
4. 如果 ≥ α 个回复都倾向 A → X 的信心 +1
5. 如果信心连续增加 β 次 → X 最终确认选 A
6. 否则回到步骤 2
```

## 网络通信复杂度

BFT 全网广播的通信复杂度是 O(n²)，Avalanche 随机采样只需 O(k·log n)，大幅降低了通信开销，使其可以支持数千个验证者。
