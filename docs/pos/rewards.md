# 出块奖励

PoS 验证者的收益来源于两部分：**区块奖励**（新增发的代币）和**交易手续费**。

## 奖励分配规则

每次验证者被选中出块，就会获得：

```
奖励 = 基础区块奖励 + 区块内所有交易的手续费
```

基础区块奖励是协议规定的固定值（或与通胀率挂钩），会随着时间的推移逐渐调整。

## 年化收益率（APY）

年化收益率取决于多个因素：

| 因素 | 影响 |
|------|------|
| 全网总质押量 | 质押越多，每个验证者分到的奖励越少 |
| 区块奖励大小 | 由协议决定 |
| 交易活跃度 | 手续费收入随网络使用率波动 |

以太坊目前的质押年化收益率约 **3-5%**，随全网质押总量动态调整。

## 复利效应

奖励通常会自动加入质押（再质押），随时间产生**复利效应**。长期持续质押的验证者可以显著放大收益。

## 与 PoW 挖矿的对比

| 维度 | PoW 挖矿 | PoS 质押 |
|------|---------|---------|
| 门槛 | 需要购买硬件 | 需要持有代币 |
| 收益稳定性 | 不稳定（算力竞争） | 相对稳定 |
| 能耗 | 极高 | 极低 |
| 流动性 | 硬件可变卖 | 代币有锁定期 |
