# 分布式挖矿

真实的比特币网络中，全球有数以千计的矿机同时参与竞争，谁先找到有效哈希，谁就赢得这一轮出块权。

## 竞争出块

所有矿机拿到**相同的待打包交易**，各自独立地尝试不同的 Nonce 值：

```
矿机 A：Nonce = 1, 2, 3 ... 100万 → ✓ 找到！广播区块
矿机 B：Nonce = 500万... → 收到 A 的区块 → 停止，接受 A 的结果
矿机 C：Nonce = 200万... → 收到 A 的区块 → 停止，接受 A 的结果
```

找到有效哈希的矿机立刻向全网广播，其他矿机验证后停止当前工作，开始挖下一个区块。

## GPU 算力的影响

算力越强，每秒尝试的 Nonce 数越多，找到答案的概率越高。演示中的三台矿机分别配备 GPU-1（慢）、GPU-2（中）、GPU-3（快），可以观察算力差异对出块概率的影响。

## 出块概率与期望

每台矿机的出块概率大致等于：

```
出块概率 = 自身算力 / 全网总算力
```

算力占全网 30% 的矿机，长期来看大约会赢得 30% 的区块。这是概率统计，短期可能偏差较大。

## 矿池

单台矿机算力有限，可能很长时间才出一个块，收益不稳定。**矿池**将许多矿工的算力合并在一起，按贡献比例分配收益，让小矿工也能获得稳定的收入。

矿池的出现提高了挖矿效率，但也带来了**算力集中化**的问题——少数大矿池控制了全网大部分算力，削弱了去中心化。
