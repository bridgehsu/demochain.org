# 质押

质押（Staking）是 PoS 系统的准入门票。验证者将代币锁定在智能合约中，换取参与共识的资格。

## 质押流程

```
1. 用户发送质押交易，锁定代币
2. 系统记录质押金额，更新验证者权重
3. 验证者进入等待队列（防止大量人同时加入/退出）
4. 激活后，验证者开始参与区块验证和出块
```

## 最低质押要求

不同协议对最低质押有不同要求：

| 网络 | 最低质押 |
|------|---------|
| Ethereum | 32 ETH |
| Cosmos | 无硬性最低（但太少则无法被选中） |
| Cardano | 无最低要求 |

以太坊设置 32 ETH 最低要求是为了控制验证者总数，避免网络通信开销过大。

## 质押权重

验证者的质押金额决定其**权重**，系统在每轮出块时按权重进行加权随机抽签：

```
Alice 质押：3200 → 权重 40%
Bob 质押：  1800 → 权重 22.5%
Charlie 质押：2500 → 权重 31.25%
Dave 质押：  500 → 权重 6.25%
```

## 委托质押

不想自己运行节点的用户，可以将代币**委托**给专业验证者，分享其收益（扣除一定服务费）。这降低了参与门槛，但也带来了集中化风险。

## 在演示中体验

在质押演示页面，你可以：

- 观察质押变化如何影响出块概率分布
