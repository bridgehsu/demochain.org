# 币基交易

每个成功挖出的区块，矿工都会获得一笔奖励——这笔奖励通过一种特殊的交易发放，叫做**币基交易（Coinbase Transaction）**。

## 什么是币基交易

币基交易是每个区块中的**第一笔交易**，也是唯一一笔没有"发送方"的交易：

```
普通交易：Alice → Bob：50 BTC
币基交易：系统 → 矿工：（区块奖励 + 手续费）BTC
```

币基交易是链上新代币**唯一的合法来源**，也是比特币总量上限（2100 万枚）被严格执行的机制所在。

## 区块奖励减半

比特币设计了**减半机制（Halving）**：每挖出 21 万个区块（约 4 年），区块奖励减半。

| 阶段 | 区块奖励 |
|------|---------|
| 2009–2012 | 50 BTC |
| 2012–2016 | 25 BTC |
| 2016–2020 | 12.5 BTC |
| 2020–2024 | 6.25 BTC |
| 2024– | 3.125 BTC |

奖励逐渐趋近于零，届时矿工收入将完全依赖手续费。这也是比特币通货紧缩的数学保证。

## 多矿机竞争与奖励分配

在分布式挖矿环境下，只有**第一个**找到有效哈希的矿机才能获得区块奖励。其他矿机的工作付诸东流。

这种"赢者通吃"的机制推动矿工不断扩大算力，催生了专业矿机（ASIC）和矿池的出现。
