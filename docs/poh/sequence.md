# 哈希序列

PoH 的基础是一条连续的 SHA256 哈希序列，每一步的输出都是下一步的输入。

## 序列生成

```
step 0: hash = SHA256("genesis")
step 1: hash = SHA256(step_0_hash)
step 2: hash = SHA256(step_1_hash)
...
step n: hash = SHA256(step_(n-1)_hash)
```

这条序列有一个关键性质：**不可并行化**。你必须按顺序一步一步计算，无法跳步。

## 验证的高效性

虽然生成序列需要逐步计算，但**验证**可以并行：

```
验证者有 step 0 和 step 1000：
- 将验证任务拆成 10 段并行计算
- 每段验证 100 步
- 所有段都通过 → 序列合法
```

验证比生成快 10 倍（拆成 10 段并行）。这让 Solana 的节点可以快速验证历史记录。

## 哈希计数器

Solana 的 PoH 产生器（通常是当前的 Leader）持续运行哈希计数器，每秒产生数十万个哈希步骤。每个哈希步骤对应一个极小的时间片。

## 在演示中体验

在序列演示页面，你可以：
- 点击"开始生成"，看哈希序列如何一步步延伸
- 观察每一步的哈希值与步骤计数
- 感受连续哈希的时间流逝
