# 哈希

哈希函数是区块链技术的基石。在 [哈希演示](/) 页面，你可以亲手操作来直观理解它的神奇之处——不需要任何编程基础，只需要敲键盘。

## 什么是 SHA-256

SHA-256（安全哈希算法 256 位）能将**任意长度的输入**映射为**固定长度的 64 位十六进制字符串**。无论输入是 1 个字节还是 1 个 G 的文件，输出永远是 64 个字符。

```
SHA256("Hello")         = 185f8db3...
SHA256("Hello!")        = 334d0162...  ← 输入只差一个字符，输出完全不同
SHA256("区块链")        = a1b2c3d4...
```

## 哈希的可视化——像素头像

在演示页面上，你的每一个输入都会实时生成一个**独一无二的像素风头像**。

这个头像的颜色和图案完全由哈希值决定：
- **前几位**决定整体色调（Hue）
- **中间位**决定 5×5 像素矩阵中每个点的亮灭

> 💡 **玩法提示**：在输入框中多敲几个空格或标点，观察头像如何瞬间变成完全不同的图案。这是最直观的"雪崩效应"演示。

## 雪崩效应（Avalanche Effect）

这是哈希函数最迷人的特性之一。输入哪怕改变一个比特（比如 `Hello` → `Hello!`），输出中大约 **50% 的位会发生翻转**，结果变得面目全非。

演示页面中，每当哈希值发生变化时，输出框会亮起**绿色闪光**，配合像素头像的瞬间重组，让你肉眼感受到"牵一发而动全身"的剧烈变化。

## 微型挖矿挑战——这就是 PoW

在演示页面底部，有一个"微型挖矿挑战"小游戏：

> **目标**：随意敲击键盘，直到碰巧算出一个**以 `0` 开头的哈希值**。

这本质上就是比特币矿机在做的事情——**穷举尝试**，不断改变输入（对于真实矿工来说是改变 Nonce），直到算出一个满足难度要求的哈希。

当你"挖"出带前导零的哈希时，页面会弹出 **🎉 挖矿成功** 的庆祝徽章。前导零越多，难度越高：
- `0` 开头：难度 × 16（平均尝试 16 次）
- `00` 开头：难度 × 256（平均尝试 256 次）
- `000` 开头：难度 × 4096（你大概率要靠程序来"作弊"了）

这正是真实的**挖矿难度（Difficulty）**——它规定了有效哈希必须满足的条件：**开头必须有 N 个零**。

## 三大核心特性

### 1. 确定性（Deterministic）
相同的输入永远得到相同的输出。今天算出的 `SHA256("a")`，一百年后再算也绝不会变。这是区块链可验证性的根基。

### 2. 单向性（One-way）
给你哈希值，你无法反推出原始数据。即使拥有超级计算机，也只能通过"穷举猜测"的方式暴力破解——这就是挖矿的本质。

### 3. 雪崩效应（Avalanche Effect）
输入数据的微小改动会导致输出剧烈变化。没有规律、无法预测，让哈希成为保护数据完整性的绝佳工具。
